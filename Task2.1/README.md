# Задание 2.1: Исправление логических ошибок в BankAccount

## Описание

Этот проект содержит **исправленную версию** класса `BankAccount` из задания 2. Все логические ошибки устранены, добавлена корректная валидация входных данных.

## Исправления

### 1. Проверка на отрицательные и нулевые суммы

- **Метод `deposit()`**: теперь выбрасывает `ValueError`, если сумма отрицательная или равна нулю
- **Метод `withdraw()`**: теперь выбрасывает `ValueError`, если сумма отрицательная или равна нулю

### 2. Проверка достаточности средств

- **Метод `withdraw()`**: теперь выбрасывает `InsufficientFundsError`, если на счёте недостаточно средств для снятия запрошенной суммы

### 3. Проверка начального баланса

- **Конструктор `__init__()`**: теперь выбрасывает `ValueError`, если начальный баланс отрицательный

## Структура проекта

- `bank_account.py` - исправленный класс банковского счёта с валидацией
- `bank_account_test.py` - тестовый класс, демонстрирующий корректную обработку ошибок
- `README.md` - документация

## Исключения

### ValueError
Выбрасывается при:
- Попытке создать счёт с отрицательным балансом
- Попытке пополнить счёт отрицательной или нулевой суммой
- Попытке снять отрицательную или нулевую сумму

### InsufficientFundsError
Выбрасывается при:
- Попытке снять больше средств, чем есть на счёте

# Доказательство корректности quick_sort через тройки Хоара

Быстрая сортировка с трехсторонним разделением — вариант алгоритма, который эффективно обрабатывает массивы с повторяющимися элементами.

## Функция quick_sort

Алгоритм работает так: выбираем случайный опорный элемент (pivot), разделяем массив на три части (меньше, равно, больше pivot), и рекурсивно сортируем левую и правую части.

**Тройка Хоара:**
```
{P: arr - массив} quick_sort(arr) {Q: результат отсортирован в порядке возрастания}
```

## Инвариант цикла разделения

В цикле, который проходит по массиву и распределяет элементы по трем спискам, инвариант такой:

После обработки k элементов:
- Все элементы `arr[0..k-1]` распределены в `left`, `middle` или `right`
- `left` содержит только элементы < pivot
- `middle` содержит только элементы = pivot  
- `right` содержит только элементы > pivot

### Доказательство инварианта разделения

**Инициализация:**
Перед циклом: k = 0, все три списка пустые.
- Условие выполняется тривиально (нет обработанных элементов)

**Сохранение:**
Предположим инвариант верен после обработки k элементов. Обрабатываем элемент `arr[k]`:
- Если `arr[k] < pivot`: добавляем в `left`. Инвариант сохраняется.
- Если `arr[k] = pivot`: добавляем в `middle`. Инвариант сохраняется.
- Если `arr[k] > pivot`: добавляем в `right`. Инвариант сохраняется.

После обработки k+1 элементов инвариант по-прежнему верен.

**Завершение:**
Когда k = len(arr), все элементы обработаны и распределены правильно.

## Доказательство корректности quick_sort

### Базовый случай

Если `len(arr) <= 1`, массив уже отсортирован по определению. Возвращаем его как есть — постусловие выполняется тривиально.

### Рекурсивный случай

Предположим, что `len(arr) > 1`. Тогда:

1. **Выбираем pivot и разделяем массив:**
   - `pivot = random.choice(arr)`
   - Разделяем на `left`, `middle`, `right` согласно инварианту выше
   - После разделения: все элементы в `left` < pivot, все в `middle` = pivot, все в `right` > pivot

2. **Рекурсивно вызываем quick_sort(left):**
   По индуктивному предположению (тройка Хоара для рекурсивного вызова):
   - Пред-условие: `left` — массив, выполняется
   - После вызова: `quick_sort(left)` отсортирован в порядке возрастания
   - Все элементы в отсортированном `left` < pivot

3. **Рекурсивно вызываем quick_sort(right):**
   По индуктивному предположению:
   - Пред-условие: `right` — массив, выполняется
   - После вызова: `quick_sort(right)` отсортирован в порядке возрастания
   - Все элементы в отсортированном `right` > pivot

4. **Композиция результатов:**
   - `quick_sort(left)` отсортирован и все элементы < pivot
   - `middle` содержит элементы = pivot (уже в правильном порядке, так как все равны)
   - `quick_sort(right)` отсортирован и все элементы > pivot
   
   Объединяем: `quick_sort(left) + middle + quick_sort(right)`
   
   Получаем отсортированный массив, так как:
   - Все элементы слева < pivot
   - Все элементы в середине = pivot
   - Все элементы справа > pivot
   - Каждая часть отсортирована внутри себя

Значит, весь результат отсортирован в порядке возрастания.

Постусловие выполняется.

## Заключение

Мы доказали корректность функции quick_sort:
- Инвариант цикла разделения сохраняется на каждой итерации
- Базовый случай тривиально корректен
- Рекурсивный случай корректен через математическую индукцию и композицию троек Хоара

Доказательство основано на тройках Хоара и математической индукции для рекурсивных вызовов.

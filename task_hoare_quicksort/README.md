# Доказательство функции quick_sort через тройки Хоара

Тройка Хоара для этой функции:

{P: arr - массив} quick_sort(arr) {Q: sorted(arr)}



## Инвариант цикла

Чтобы доказать корректность, нужно определить инвариант цикла разделения.

В цикле, который проходит по массиву и распределяет элементы по трем спискам (left, middle, right), инвариант следующий: на каждой итерации все уже обработанные элементы правильно распределены по трем спискам в зависимости от их отношения к опорному элементу.


## Доказательство инварианта цикла

### Инициализация

Перед началом цикла: k = 0, left = [], middle = [], right = []

Проверка инварианта: Все элементы распределены в списки верно, так как диапазон пустой


### Сохранение инварианта

Предположим, что перед какой-то итерацией инвариант выполняется:
- Все элементы arr[0..k-1] распределены в left, middle или right
- left содержит только элементы < pivot
- middle содержит только элементы = pivot
- right содержит только элементы > pivot

Обрабатываем элемент arr[k]:
- Если arr[k] < pivot: добавляем его в left
- Если arr[k] = pivot: добавляем его в middle
- Если arr[k] > pivot: добавляем его в right

Инвариант сохраняется.

После итерации:
- Все элементы arr[0..k] распределены в left, middle или right
- left по-прежнему содержит только элементы < pivot
- middle по-прежнему содержит только элементы = pivot
- right по-прежнему содержит только элементы > pivot

Инвариант сохраняется.

### Завершение


В этот момент:
- Все элементы arr[0..len(arr)-1] распределены в left, middle или right
- left содержит только элементы < pivot
- middle содержит только элементы = pivot
- right содержит только элементы > pivot

Разделение корректно

## Доказательство корректности quick_sort

### Базовый случай

Если len(arr) <= 1, функция возвращает массив без изменений, т.к. vассив из нуля или одного элемента отсортирован по определению. Постусловие выполняется.

### Рекурсивный случай

Предположим, что len(arr) > 1. Тогда:

1. Выбираем pivot и разделяем массив:
   - pivot = random.choice(arr) — выбираем случайный элемент массива как опорный
   - Разделяем массив на left, middle, right согласно инварианту выше


2. Рекурсивно вызываем quick_sort(left):
   По индуктивному предположению :
   - Предусловие: left — массив, выполняется
   - После вызова: quick_sort(left) отсортирован в порядке возрастания
   - Все элементы в отсортированном quick_sort(left) < pivot (так как все элементы left < pivot)

3. Рекурсивно вызываем quick_sort(right):
   По индуктивному предположению:
   - Предусловие: right — массив, выполняется
   - После вызова: quick_sort(right) отсортирован в порядке возрастания
   - Все элементы в отсортированном quick_sort(right) > pivot (так как все элементы right > pivot)

4. Композиция результатов:
   Объединяем: quick_sort(left) + middle + quick_sort(right)
   
   Получаем отсортированный массив, так как:
   - quick_sort(left) отсортирован и все его элементы < pivot
   - middle содержит элементы = pivot (уже в правильном порядке, так как все равны)
   - quick_sort(right) отсортирован и все его элементы > pivot
   - Каждая часть отсортирована внутри себя
   - Элементы расположены в правильном порядке относительно друг друга

Значит, весь результат отсортирован в порядке возрастания.

Постусловие выполняется.

## Реализация функции quick_sort

python
import random

def quick_sort(arr):

    if len(arr) <= 1:
        return arr
    
    pivot = random.choice(arr)
    left = []
    middle = []
    right = []
    
    for x in arr:
        if x < pivot:
            left.append(x)
        elif x > pivot:
            right.append(x)
        else:
            middle.append(x)
    
    return quick_sort(left) + middle + quick_sort(right)

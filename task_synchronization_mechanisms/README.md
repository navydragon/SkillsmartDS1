# Механизмы синхронизации в Python

Этот проект содержит пять оригинальных примеров различных механизмов синхронизации для многопоточного программирования в Python. Каждый пример демонстрирует практическое применение конкретного механизма синхронизации и помогает понять, когда и как его использовать.

## Структура проекта

- `example1_mutex.py` - Мьютексы (Lock)
- `example2_semaphore.py` - Семафоры (Semaphore)
- `example3_barrier.py` - Барьеры (Barrier)
- `example4_event.py` - События (Event)
- `example5_executor.py` - ThreadPoolExecutor (ExecutorService)

## Пример 1: Мьютексы (Lock)

**Файл:** `example1_mutex.py`

**Описание:** Демонстрация использования `threading.Lock` для защиты общего ресурса от состояния гонки (race condition).

**Пример использования:** Потокобезопасный счетчик посещений веб-сайта.

**Ключевые концепции:**
- Защита критических секций кода
- Предотвращение состояния гонки
- Автоматическое управление блокировкой через `with` statement

**Запуск:**
```bash
python tasks/task_synchronization_mechanisms/example1_mutex.py
```

**Что демонстрирует:**
- Проблему потери данных при отсутствии синхронизации
- Правильное решение с использованием мьютекса
- Гарантию атомарности операций

## Пример 2: Семафоры (Semaphore)

**Файл:** `example2_semaphore.py`

**Описание:** Демонстрация использования `threading.Semaphore` для ограничения количества одновременного доступа к ограниченному ресурсу.

**Пример использования:** Пул подключений к базе данных с ограничением количества одновременных подключений.

**Ключевые концепции:**
- Управление доступом к ограниченным ресурсам
- Контроль количества одновременных операций
- Пул ресурсов

**Запуск:**
```bash
python tasks/task_synchronization_mechanisms/example2_semaphore.py
```

**Что демонстрирует:**
- Ограничение количества одновременных подключений
- Управление пулом ресурсов
- Преимущества семафора перед простой блокировкой

## Пример 3: Барьеры (Barrier)

**Файл:** `example3_barrier.py`

**Ключевые концепции:**
- Синхронизация группы потоков
- Координация выполнения на определенной точке
- Гарантия одновременного старта следующей фазы

**Запуск:**
```bash

```

**Что демонстрирует:**
- Синхронизацию потоков перед началом обработки
- Координацию параллельных вычислений
- Практические применения барьеров

## Когда использовать каждый механизм

### Lock (Мьютекс)
- **Когда:** Нужно гарантировать, что только один поток может выполнять критическую секцию кода
- **Примеры:** Счетчики, обновление общих структур данных, операции чтения-записи

### Semaphore (Семафор)
- **Когда:** Нужно ограничить количество потоков, имеющих доступ к ресурсу одновременно
- **Примеры:** Пул подключений к БД, ограничение сетевых запросов, управление файловыми дескрипторами

### Barrier (Барьер)
- **Когда:** Группа потоков должна синхронизироваться на определенной точке перед продолжением
- **Примеры:** Параллельная обработка данных, инициализация распределенных систем, синхронизация вычислений

### Event (Событие)
- **Когда:** Потоки должны ждать наступления определенного события или условия
- **Примеры:** Координация потоков, управление жизненным циклом, producer-consumer паттерн

### ThreadPoolExecutor (ExecutorService)
- **Когда:** Нужно эффективно управлять множеством задач с использованием пула потоков
- **Примеры:** Параллельная обработка данных, выполнение множества независимых задач, оптимизация использования ресурсов

# Доказательство функции findMax через тройки Хоара

## Что делает функция

Функция `findMax(arr)` просто находит самое большое число в массиве. Массив должен быть непустым, иначе функция не имеет смысла.

Тройка Хоара для этой функции выглядит так:
```
{P: len(arr) > 0} findMax(arr) {Q: result = max(arr)}
```

То есть, если массив не пустой, то после выполнения функции результат будет равен максимуму всех элементов массива.

## Инвариант цикла

Чтобы доказать корректность, нужно определить инвариант цикла.

Для нашей функции инвариант такой:
```
I: 0 <= i <= len(arr) и result = max(arr[0], arr[1], ..., arr[i-1])
```

Простыми словами: на каждой итерации переменная `i` находится в правильных пределах, а `result` содержит максимум всех элементов, которые мы уже просмотрели (от начала массива до текущего индекса i-1).

## Доказательство

Доказательство состоит из трех частей: инициализация, сохранение и завершение.

### Инициализация

Перед началом цикла у нас:
- `i = 1` (цикл начинается с первого элемента, нулевой уже обработан)
- `result = arr[0]` (взяли первый элемент как начальное значение максимума)

Проверяем инвариант:
- `0 <= 1 <= len(arr)` — это верно, потому что массив не пустой (это наше пред-условие)
- `result = arr[0] = max(arr[0])` — максимум одного элемента равен самому элементу, это очевидно

Значит, инвариант выполняется в самом начале.

### Сохранение инварианта

Теперь нужно показать, что если инвариант был верен до итерации, то он останется верным и после.

Предположим, что перед какой-то итерацией инвариант выполняется:
- `0 <= i < len(arr)` 
- `result = max(arr[0], arr[1], ..., arr[i-1])`

Что происходит на этой итерации? Мы проверяем `if arr[i] > result`:
- Если `arr[i]` больше текущего максимума, обновляем `result = arr[i]`
- Если нет, оставляем `result` как есть

После итерации:
- `i` становится `i + 1`
- `result` теперь равен `max(result, arr[i])`, что равно `max(max(arr[0..i-1]), arr[i])`, а это в свою очередь равно `max(arr[0..i])`

Получается, что инвариант все еще выполняется:
- `0 <= i <= len(arr)` (i увеличилось, но не вышло за границы)
- `result = max(arr[0], arr[1], ..., arr[i-1])` (теперь result содержит максимум элементов от 0 до i-1)

Инвариант сохранился.

### Завершение

Цикл заканчивается, когда `i` становится равным `len(arr)`. 

В этот момент:
- `i = len(arr)`
- `result = max(arr[0], arr[1], ..., arr[len(arr)-1])`

А это и есть `max(arr)` — максимум всего массива! 

Значит, постусловие выполняется: `result = max(arr)`.

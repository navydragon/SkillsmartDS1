# Тройки Хоара - доказательство корректности функции findMax с инвариантом цикла

## Функция `findMax(arr)`

Функция находит максимальное значение в непустом массиве чисел.

**Тройка Хоара:**
```
{P: len(arr) > 0} findMax(arr) {Q: result = max(arr)}
```

## Инвариант цикла

**Инвариант цикла I**: `0 <= i <= len(arr)` и `result = max(arr[0], arr[1], ..., arr[i-1])`

Инвариант описывает состояние программы, которое остается истинным на каждой итерации цикла. Он утверждает, что:
- Переменная `i` находится в допустимом диапазоне от 0 до длины массива
- Переменная `result` содержит максимум всех элементов массива от индекса 0 до индекса i-1

## Доказательство корректности

### 1. Инициализация

До начала первой итерации цикла:
- `i = 1` (цикл начинается с индекса 1)
- `result = arr[0]` (инициализирован первым элементом массива)

Проверка инварианта:
- `0 <= 1 <= len(arr)` - условие выполняется, так как `len(arr) > 0` (пред-условие)
- `result = arr[0] = max(arr[0])` - максимум одного элемента равен самому элементу

Инвариант истинен в начале цикла.

### 2. Сохранение инварианта

Предположим (доказательство по индукции), что инвариант истинен до некоторой итерации цикла:
- `0 <= i < len(arr)` и `result = max(arr[0], arr[1], ..., arr[i-1])`

Во время выполнения итерации:
- Выполняется проверка: `if arr[i] > result`
- Если условие истинно, то `result = arr[i]`
- Если условие ложно, то `result` остается прежним

После выполнения итерации:
- `i` увеличивается на 1: `i = i + 1`
- `result = max(result, arr[i]) = max(max(arr[0..i-1]), arr[i]) = max(arr[0..i])`

Таким образом, инвариант по-прежнему истинен:
- `0 <= i <= len(arr)` (так как i увеличилось на 1, но не превысило len(arr))
- `result = max(arr[0], arr[1], ..., arr[i-1])` (так как result теперь содержит максимум элементов от 0 до i-1)

Инвариант сохраняется на каждой итерации.

### 3. Завершение

Цикл завершается, когда `i` становится равным `len(arr)`.

На этом этапе:
- Инвариант после последней итерации: `i = len(arr)` и `result = max(arr[0], arr[1], ..., arr[len(arr)-1])`
- Это означает, что `result = max(arr)` - максимум всех элементов массива

Следовательно, постусловие выполняется: `result = max(arr)`

# Тройки Хоара - композиция программ

## Реализованные функции

### 1. Функция `abs_value(x)`

Вычисляет модуль числа x.

**Тройка Хоара:**
```
{P: x - действительное число} abs_value(x) {Q: result = |x|}
```

**Формальное доказательство:**

1. **Пред-условие P**: x - действительное число (любое float)

2. **Выполнение команды:**
   - Если x >= 0, то result = x = |x|
   - Если x < 0, то result = -x = |x|

3. **Пост-условие Q**: result = |x|
   В обоих случаях результат равен модулю x, что доказывает корректность.



### 2. Функция `max_value(a, b)`

Вычисляет максимум из двух чисел.

**Тройка Хоара:**
```
{P: a, b - действительные числа} max_value(a, b) {Q: result = max(a, b)}
```

**Формальное доказательство:**

1. **Пред-условие P**: a и b - действительные числа

2. **Выполнение команды:**
   - Если a >= b, то result = a = max(a, b)
   - Если a < b, то result = b = max(a, b)

3. **Пост-условие Q**: result = max(a, b)
   В обоих случаях результат равен максимуму из a и b.



### 3. Функция `max_abs(a, b)` - композиция

Вычисляет максимум модулей двух чисел: max(|a|, |b|).

Эта функция демонстрирует **композицию троек Хоара** — она использует уже доказанные функции `abs_value` и `max_value`.

**Композиция троек Хоара для доказательства корректности:**

**Шаг 1: Вычисление |a|**
```
{P1: a - действительное число} abs_value(a) {Q1: |a| = abs_value(a)}
```

**Шаг 2: Вычисление |b|**
```
{P2: b - действительное число} abs_value(b) {Q2: |b| = abs_value(b)}
```

**Шаг 3: Вычисление max(|a|, |b|)**
```
{P3: |a|, |b| - действительные числа} max_value(|a|, |b|) {Q3: result = max(|a|, |b|)}
```

**Формальное доказательство композиции:**

1. **Пред-условие P**: a, b - действительные числа

2. **После выполнения abs_value(a):**
   - Пост-условие Q1: abs_a = |a|
   - abs_a >= 0 (свойство модуля)

3. **После выполнения abs_value(b):**
   - Пост-условие Q2: abs_b = |b|
   - abs_b >= 0 (свойство модуля)

4. **После выполнения max_value(abs_a, abs_b):**
   - Пост-условие Q3: result = max(|a|, |b|)

5. **Итоговое пост-условие Q**: result = max(|a|, |b|)

Таким образом, композиция троек Хоара доказывает корректность функции `max_abs`.

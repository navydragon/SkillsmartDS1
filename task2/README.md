# Задание 2: Ложная уверенность в исходах

## Описание

Этот проект демонстрирует проблему **ложной уверенности в коде**. Код работает без исключений и проходит простые тесты, но содержит серьёзные логические ошибки, которые могут привести к латентным проблемам в продакшене.

## Проблемы в коде

Класс `BankAccount` содержит следующие баги:

1. **Нет проверки на отрицательные суммы** в методах `deposit()` и `withdraw()`
   - Можно "пополнить" счёт отрицательной суммой (фактически снятие)
   - Можно "снять" отрицательную сумму (фактически пополнение)

2. **Баланс может стать отрицательным**
   - Метод `withdraw()` не проверяет, достаточно ли средств на счёте
   - Можно снять больше, чем есть на балансе

## Структура проекта

- `bank_account.py` - класс банковского счёта с багами
- `bank_account_test.py` - тестовый класс, демонстрирующий проблемы

## Запуск

```bash
# Запуск тестов
python task2/bank_account_test.py
```

## Ожидаемое поведение

Код должен работать без исключений, но демонстрировать логические ошибки:
- Принятие отрицательных сумм
- Возможность отрицательного баланса
- Отсутствие валидации входных данных
